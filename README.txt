# LPGD Website

Open `index.html` in a browser to preview the website.

Before publishing:
1. Replace the placeholder email in the Contact section.
2. Add LPGD's official phone number and service areas.
3. Publish the site on a web host and connect a domain.
4. Add the website URL to the verified Google Business Profile.
5. Verify the website in Google Search Console and request indexing.

For LPGD as a service-area plumbing business, Google recommends accurately specifying the areas actually served rather than using an arbitrary radius.
